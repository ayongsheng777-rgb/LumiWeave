# 08 AI 能力报告 — 绵绣 LumiWeave

> Phase 10：AI 专项验收

## 一、模型能力（实测 + 库内数据）

- **多模型真实在用**：GLM-5.2 / DeepSeek-V3 / DeepSeek-V4-Pro / Qwen2.5-72B / Kimi-K2.6 / Nex-N2-Pro / Qwen-Image / Wan2.2 等 10+ 模型，30 天 792 次真实调用、89.8 万 tokens、成本 ¥9.12
- **Provider 体系**：9 个 Provider 配置（LLM/出图/视频/语音/向量全覆盖），api_key 脱敏完整，`best_provider(task_type)` 自动优选路由
- **稳定性**：近日调用成功率 ~99%（早期 15% 失败系配置调试）；统一错误码 + 超时优雅降级（实测 60s 超时返回结构化错误，不崩）

## 二、Prompt 工程

- **统一 LLM 网关**（provider_gateway.py）+ **prompt 学习/RAG**：489 条知识库条目，余弦相似度检索（>0.3 阈值）+ 拆词 OR ILIKE 兜底（已修"整句 ILIKE 必失败"坑）
- **提示词优化器**：先搜知识库/技能命中参考优化，无匹配 AI 兜底（实测命中 KB 返回 source=kb）
- **硬约束提示词**：分镜生成严格 N 镜 + 时长归一化兜底（截断/补镜/舍入差补偿），实测 20s/4 镜精确输出 4 镜
- **Skill 中央仓库**：h3-prompt-writing 等 7 个技能，manifest + 参数 schema + 权限控制

## 三、Agent / 工具调用

- **MCP 40+ 工具**：canvas(7)/workflow(6)/asset(4)/provider(3)/project(1)/film(9)/scene(7)/marketing(6)，实测 initialize + tools/list 正常
- **执行安全**：⚠️ 权限模型未强制（见安全报告 S3，P1）——工具调用层只验 token 有效性不验权限
- **AI 自动搭建**：一句话 → 5 节点 4 边工作流（历史实测）；film.build_story 一键骨架（24 项验证全绿）

## 四、RAG / 视觉

- Vision 专用路由：自动探测 vl/vision 模型走多模态消息，拆镜识别实测输出「中景/三分法/自然光/暖调」
- embedding 未配真向量服务时本地哈希降级（设计决策：保证 docker 从零启动，合理）

## 五、AI 链路缺口

| # | 问题 | 等级 |
|---|---|---|
| AI1 | 主对话 /api/ai/chat 活跃模型解析落到无 key 配置，60s 超时（场景动作链路正常，见功能报告 F1） | P1 |
| AI2 | MCP 工具执行无权限校验，read token 可触发付费生成 | P1 |
| AI3 | 失败调用也计入 token_usage_log（success=f）✅ 但无失败原因聚合视图，121 条失败只能逐条翻 | P3 |
| AI4 | 幻觉/准确率无系统性评估集——质量靠人工审核环节兜底（导演台 REVIEWING 状态设计合理） | P3 |

## 六、结论

AI 能力是本项目**最强维度**：多模型真实在用、计费全链路可追溯、Prompt 工程有硬约束与兜底、MCP 工具体系完整。缺口在主对话入口配置与工具权限。**AI 单项得分：85/100**。
