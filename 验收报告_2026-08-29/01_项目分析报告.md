## 项目识别卡

| 项 | 内容 |
|---|---|
| 项目名称 | 绵绣 LumiWeave |
| 项目类型 | AI 原生创作画布平台（Web 应用 + MCP Server） |
| 业务目标 | 以 DAG 工作流画布 + 专业场景画布为核心，AI 作为画布的操作系统，覆盖影视创作、电商物料、电商短剧三类内容生产闭环 |
| 用户群体 | 单用户自托管（作者本人），外部 AI 编程智能体（Codex/Claude/WorkBuddy 经 MCP 接入） |

| 技术栈 | 后端 FastAPI (Python 3.12) + asyncpg；前端 React 18 + TypeScript + Vite 5 + Tailwind + React Flow + Zustand；MCP Server (mcp 2.1.0, stdio + streamable-http 双模式) |
| 代码规模 | 后端 ~90+ py 文件（最大 scene/actions.py 2144 行）；前端 src 多组件（最大 SceneNodeEditPanel.tsx 1063 行、api.ts 927 行） |
| 数据库 | PostgreSQL 16.4（27 张表，真实数据：token_usage_log 791 行、tasks 231、prompt_knowledge 489、director_task 52）+ Redis 7.4（配置存在但代码零调用，死依赖） |
| 运行方式 | `docker compose up -d`，前端 3010 / 后端 8900 / MCP 8901 / PG 5435 / Redis 6385 |
| 依赖服务 | 硅基流动（LLM/出图/视频/语音/向量）、MiniMax H3（视频）、ComfyUI（本地/云端渲染，可选）、飞书 Webhook（日报，可选） |

## 版本演进

V2 重构（2026-08-24）→ V2.1 工作流画布（08-25）→ V2.2 MCP 改造（删 Agent 中心，08-25）→ V2.5 专业场景画布五轮（08-26~27）→ V2.7 视频/音频编辑器 → V2.8 场景画布 UI 重构 + 导演台骨架模式（08-28）。当前 master 即 V2.8 形态，AGENTS.md 维护手册保持同步。

## 核心能力地图

1. **DAG 工作流画布**：13 类影视节点，连线持久化、真实执行、结果回写、AI 一句话搭建
2. **专业场景画布**：电商物料 / 电商短剧 / 影视拉片三场景，注册表驱动（registry.py 唯一真源）
3. **AI 导演台**：故事→分镜→资产图→分镜视频一键骨架搭建
4. **MCP Server**：40+ 工具（canvas/workflow/asset/provider/project/film/scene/marketing），Bearer token 认证
5. **算力路由**：本地 ComfyUI 队列 + 云端大显存分发；云端 Provider 自动优选
6. **Token 计费**：全链路 usage 落库，按日/模型/场景汇总，费用折算 ¥9.12（30 天实测数据）
